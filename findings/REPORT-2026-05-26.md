## Patterns

1. **MCP-vs-direct disagreements remain the most valuable signal.** Both new findings against MCP (curator/02 pagination cursor, developer/02 workflow_rid drop) were caught only because §3.4 cross-channel verification was mandatory. Neither broke a deliverable — both would have stayed invisible without the discipline.
2. **"Silently degenerate" failure mode appears twice this run.** developer/01 (Validation bags silently produce a 50-byte non-execution) and curator/01 (small variant silently equals full variant) both ship without failure signals. The pattern: an unrecognized input doesn't error, it produces a defensible-looking output. Worth a cross-cutting story in the skill docs (e.g., explicit `bag_role` handling in execution-lifecycle; an explicit "verify small-vs-full members differ" check in dataset-lifecycle).
3. **Description-rot in two places.** curator/03 (bootstrap descriptions stale at `--num-images 500`) and analyst/02 (execution description bound to wrong config name). Distinct root causes, same symptom: structured fields end up with text that contradicts the catalog state. C03 covers the loader half; analyst/02 is the notebook-runner half.
4. **The denormalize surface itself is robust.** All three reconciliation dimensions (row count, RID set, label distribution) agreed between channels on CSA. The single denormalize finding (analyst/01) is a describe-vs-run UX gap, not a data-integrity issue. This is meaningful — the surface that produced the most findings on 2026-05-25 (A01/A02/A04) is now solid.
